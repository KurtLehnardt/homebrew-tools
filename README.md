# homebrew-tools

Custom Homebrew tap for Granted and other tools.

## Installation

Add the tap:
```bash
brew tap KurtLehnardt/tools
```

Install Granted:
```bash
brew install granted
```

## Usage

Start Granted:
```bash
granted
```

The application will start and open in your browser at `http://localhost:3000`.

## Updating

```bash
brew upgrade granted
```

## Uninstalling

```bash
brew uninstall granted
brew untap KurtLehnardt/tools
```

## About Granted

Granted is a grant matching tool that helps you find funding opportunities. For the full experience with auto-update and menu bar integration, download the native installer from:

https://github.com/KurtLehnardt/granted/releases
